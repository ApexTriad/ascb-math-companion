# ASCB: Mathematics in the Modern World - Your Companion

A single-page study site: login / create account, six topics with live tools, quizzes, glossary.

## Run it in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click `index.html` > "Open with Live Server".
   (You can also just double-click `index.html` to open it in a browser.)

## Files
- `index.html`  page structure
- `style.css`   all styling
- `script.js`   tools, quizzes, login, navigation
- `images/`     logo and team photos

Note: the login is a front-end demo only. Passwords are not stored or checked.
