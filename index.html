About Us

Our mission: make mathematics useful and approachable for people who want to work with computers.

Who we are

Mathematics for Computing is a learning companion for students of computing and information technology. We explain the math ideas that sit underneath programming, then let you try them right away.

What you will find here

  • Six topics, from the nature of mathematics to statistics for data analytics
  • A clear learning outcome for every topic
  • Interactive tools you can use without installing anything

How to use this site

  • Start on Home and pick a topic card, or use the menu at the top.
  • Read the topic list and outcome, then try the tool.
  • Use the menu at the top, or the dots on the right of a wide screen, to move between topics.

Example: math inside a computer

A computer stores everything as bits (0 or 1). With 3 bits you can tell 2 × 2 × 2 = 8 things apart. This is how many bits a program needs to give every item its own code.

Problem Solving and Reasoning

Learning outcome: Apply mathematical reasoning in debugging and algorithm design.
  1. Read the bug report
  2. Pick a strategy
  3. Run the plan
  4. Test and learn

Topics

  • Polya’s 4-step process
  • Inductive and deductive reasoning
  • Heuristics in computing

Inductive: the function worked on three inputs, so it probably works. Deductive: the loop invariant holds, so the result must be correct.
